# Khung trả lời theo từng dạng câu

Thuộc **khung**, không thuộc bài. Khi vào phòng thi, bạn chỉ cần "đổ" nội dung của mình vào khung.

---

## 1. Câu mô tả (Description) – thì hiện tại

```
① Trả lời thẳng      → "My favorite ___ is ___, which is located in ___."
② Tổng quan          → "It's a ___ (big/small/modern/cozy) place."
③ Chi tiết 1         → "When you walk in, the first thing you see is ___."
④ Chi tiết 2         → "There's also ___ / Next to that, there's ___."
⑤ Điều thích nhất    → "What I like most about it is ___ because ___."
⑥ Điểm trừ (tuỳ chọn)→ "The only downside is ___."
⑦ Kết                → "So overall, it's a place I really love."
```

## 2. Câu thói quen (Routine) – hiện tại đơn + tần suất

```
① Tần suất           → "I usually ___ about ___ times a week / every weekend."
② Trước              → "Before ___, I always ___."
③ Trong (trình tự)   → "First, ___. Then, ___. After that, ___."
④ Sau                → "Once I'm done, I ___."
⑤ So sánh (tuỳ chọn) → "On weekdays ___, but on weekends ___."
⑥ Cảm nhận/kết       → "It's the best way for me to ___."
```

**Trạng từ tần suất:** always · usually · often · sometimes · rarely · never · once in a while · every now and then

## 3. Câu kinh nghiệm quá khứ (Past experience) – ⭐ câu ăn điểm

Dùng **khung kể chuyện 5W1H + cảm xúc**:

```
① Mở                 → "Oh, I remember one time ___. It was about ___ ago."
② Bối cảnh           → Khi nào? Ở đâu? Với ai? Đang làm gì?
                        "I was ___ with my ___ at ___."
③ Diễn biến          → "At first, ___. Then, all of a sudden, ___."
④ Cao trào / sự cố   → "The problem was that ___ / I couldn't believe it!"
⑤ Giải quyết         → "So, we decided to ___. Luckily, ___."
⑥ Kết quả            → "In the end, ___."
⑦ Cảm xúc / bài học  → "It was such a ___ experience. I learned that ___.
                        Since then, I always ___."
```

**Từ nối kể chuyện:** at first · then · after that · all of a sudden · suddenly · meanwhile · luckily · unfortunately · eventually · in the end · since then

**Ngữ pháp nên khoe:**
- Quá khứ tiếp diễn: *"I **was walking** home when it **started** to rain."*
- Quá khứ hoàn thành: *"By the time we got there, the show **had** already **started**."*
- *It turned out that…* / *I ended up + V-ing…*

## 4. Câu so sánh (Comparison) – quá khứ ↔ hiện tại

```
① Trả lời thẳng      → "I think ___ has changed a lot over the years."
② Quá khứ            → "In the past / When I was a kid, ___ used to ___."
③ Hiện tại           → "Nowadays / These days, ___."
④ Lý do              → "This is mainly because ___."
⑤ Ưu/nhược           → "On the one hand, ___. On the other hand, ___."
⑥ Ý kiến & kết       → "Personally, I prefer ___ because ___."
```

**So sánh:** much / a lot / way + bigger · more convenient · less ___ than · not as ___ as · compared to…

## 5. Role-play 11 – Hỏi 3–4 câu

```
① Chào + lý do gọi    → "Hi, I'm calling because I'm interested in ___."
② Câu hỏi 1           → "First of all, could you tell me ___?"
③ Câu hỏi 2           → "Also, I was wondering if ___."
④ Câu hỏi 3           → "And how much / how long / when ___?"
⑤ Câu hỏi 4           → "Oh, and one more thing — ___?"
⑥ Cảm ơn + kết        → "Great, thank you so much. I'll ___. Have a nice day!"
```

## 6. Role-play 12 – Giải quyết vấn đề

```
① Chào + danh tính    → "Hi, this is ___. I ___ (bought/booked) ___ yesterday."
② Nêu vấn đề          → "I'm afraid there's a problem. ___."
③ Hậu quả/cảm xúc     → "So I won't be able to ___, which is a bit frustrating."
④ Phương án 1         → "Would it be possible to ___?"
⑤ Phương án 2         → "If that doesn't work, maybe I could ___."
⑥ Phương án 3         → "Or, as a last option, ___."
⑦ Kết                 → "Please let me know what works best. Thanks for understanding."
```

## 7. Câu 15 – Vấn đề xã hội

```
① Nêu vấn đề          → "One of the biggest concerns people have about ___ is ___."
② Giải thích + số liệu→ "For example, ___."
③ Vấn đề thứ 2        → "Another issue is ___."
④ Tại sao quan trọng  → "This is important because it affects ___."
⑤ Giải pháp           → "In my opinion, ___ should ___."
⑥ Liên hệ bản thân    → "Personally, I ___."
```

## ✅ Checklist sau mỗi lần tự luyện

- [ ] Nói đủ **1:30 – 2:00**?
- [ ] Có **trả lời thẳng** ngay câu đầu?
- [ ] Có ít nhất **2 chi tiết cụ thể** (tên, số, thời gian)?
- [ ] Câu quá khứ: dùng **đúng thì quá khứ** xuyên suốt?
- [ ] Có dùng **từ nối** và **filler** tự nhiên?
- [ ] Có **câu kết**?
