# Flashcards OPIc IH

**Cách dùng trên điện thoại:** che cột *English*, nhìn cột *Tiếng Việt* rồi tự nói ra cụm tiếng Anh và **đặt một câu về bản thân bạn**. Sau đó mở ra đối chiếu.

**Dùng với Anki:** tải file [`anki-opic-ih.tsv`](anki-opic-ih.tsv) → mở Anki → *File → Import* → chọn file. Cột và tag đã được khai báo sẵn trong file.

> File này được tạo từ `anki-opic-ih.tsv`. Muốn thêm thẻ, hãy sửa file `.tsv` rồi chạy lại `./build-md.sh`.
